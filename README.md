#  Velvet Beauty

Landing page moderna e responsiva para um salão de beleza, com foco em experiência visual, animações suaves e conversão de clientes via WhatsApp.

🔗 Acesse o projeto:  
https://velvet-beauty-2026.netlify.app/

---

##  Sobre o projeto

O **Velvet Beauty** é um site desenvolvido para apresentar serviços e produtos de um salão de beleza de forma elegante e envolvente.

O objetivo principal é:
- Destacar os serviços oferecidos
- Apresentar produtos de forma visual
- Facilitar o agendamento de clientes
- Criar uma experiência moderna com animações

---

##  Funcionalidades

-  Animações com **Intersection Observer**
-  Layout totalmente responsivo
-  Call-to-action direto para o WhatsApp
-  Navegação suave entre seções (scroll behavior)
-  Design moderno com foco em estética visual
-  Integração com Google Maps

---

##  Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Intersection Observer API  


---

##  Layout e Design

O projeto utiliza:
- Gradientes modernos
- Tipografia elegante (Montserrat)
- Paleta focada em tons de rosa e vinho
- Efeitos de entrada suaves (fade, blur, translate)

---

##  Animações

As animações são ativadas conforme o usuário rola a página usando:

- `IntersectionObserver`

Elementos animados:
- Hero section
- Imagens dos serviços
- Textos descritivos
- Produtos
- Call-to-action

---

##  Responsividade

O site foi adaptado para diferentes tamanhos de tela:

- Desktop
- Tablet
- Mobile

Utilizando media queries em:
- 1250px
- 770px
- 608px

## Contato / Conversão

- Botão direto para WhatsApp com mensagem pré-definida
- Seção de contato com endereço
- Mapa incorporado
